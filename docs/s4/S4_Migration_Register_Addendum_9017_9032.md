## 1. Common properties

- Every migration below is **expand-only**:
  - no table is dropped or rewritten;
  - no column is removed;
  - none creates or alters a table;
  - a changed function keeps its signature.
- Every migration that creates or replaces a function calls `select bnx.apply_grants();` after its function definitions, so the grants and the privilege audit (9002) cover the new bodies. 9022 changes only catalog comments and does not call it.
- Every migration is applied to PG16 and PG17 in every local full regression and in CI.
- 9014 and 9015 remain unassigned (L-9016-8: an Owner decision).
- The "catalog delta" migrations change only `COMMENT ON FUNCTION` metadata (the `bnx-tools/1.0` catalog). They are generated by `tools/s4/catalog_build.py` and never edited by hand (D-CORE9-2).
