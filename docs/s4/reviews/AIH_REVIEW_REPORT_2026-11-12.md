## 4. Not verified

- **No real AI host.** Claude, ChatGPT, their DCR/CIMD behaviour, the MCP Apps / Apps SDK message names and iframe topology (so whether a sibling app can actually reach the card, RV-AIH-04) and PV-AIH/PV-UI are untested.
- **No Cloudflare runtime.** Workers `fetch` redirect semantics for CIMD, KV consistency and concurrency for the DCR limit, `cf-connecting-ip` trust, request-size limits, isolate behaviour and the Neon driver were exercised only through the node adapter (in-memory KV, `pg` pool of 4).
- **No TLS / deployed instance URL**; resource and issuer strings were checked only for `https://app.balnexa.test` (and one `BNX_PUBLIC_URL` variant).
- **The PWA consent and connections screens were not attacked in a browser** (e.g. a hash change between describe and approve, framing); only their HTTP calls were. COOP/XFO headers were read, not exercised.
- **Real-world reachability of RV-AIH-02 and RV-AIH-11:** the SIN-shaped value was injected by the superuser; I did not find a normal write path that stores one past guard C2, nor an AI-reachable result containing a bare integer array.
- **Long time windows** (30-day refresh expiry, sliding rotation over days) were not simulated; only code expiry was (by moving `expires_at`).
- **Hex-exempt keys** of the SIN detector (`*_id`, `*_key`, `*_sha256` with a 32/40/64/128-hex value) were not probed end to end.
- **GitHub state** of PRs #13/#14 was not queried (read-only rule; local branches equal `origin/*`).
- Owner-private packages and `requirements/owner_sources/` were out of scope and not opened.
