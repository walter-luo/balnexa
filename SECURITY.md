# Security policy

Report a security problem **privately**, never in a public issue: use the **Security** tab of this repository → **Report a vulnerability** (GitHub private vulnerability reporting). Only the project Owner sees the report.

Report privately when you find:
- a way to read or change another household's data, or to act without the right grant;
- a way around the SIN guard or the card-number guard, or a place where such a value is stored, logged or shown;
- a secret or real personal data in this repository or its history;
- anything an AI assistant connection can do beyond its consent.

Please include the release (Settings → Version, or `release` in `/app/config.json`), the steps, and what you observed. Use synthetic data only; never send a real SIN, card number or statement, not even privately.

Ordinary problems, wrong refusals and ideas go to the public issue forms (`docs/s4/Issue_and_Release_Process.md`).

Fixes for reported vulnerabilities are published in a release (`CHANGELOG.md`) after the fix is available. A reporter who wishes is credited.
