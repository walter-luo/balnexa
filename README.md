# Balnexa

**AI-First Household Financial Management**

Balnexa is an open-development project for a bilingual (English/Chinese), independently deployable household financial management application.

## Project Goals

- One shared application codebase supporting independent household instances.
- Separate PostgreSQL databases and file storage for each household.
- Deterministic double-entry accounting and financial reconciliation.
- A complete Progressive Web App (PWA) usable without AI.
- Optional AI assistance through authorized REST/MCP interfaces.
- Multi-currency accounts, financial reports, and evidence traceability.
- Cloud-native deployment using Architecture C / H-A.

## Development Status

**Early development — not production-ready.**

Architecture, implementation, integration, and independent acceptance testing are in progress. The features above describe project objectives, not verified completed functionality.

## Security

Never commit real financial statements, account credentials, personal financial records, API keys, or production secrets to this repository.
